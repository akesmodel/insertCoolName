Gradebook Extension
by Abby Hunter Kesmodel

# Description
An updated version of Gradebook. In addition to all the functions of Gradebook 1.0, this extension includes the following:
- A  new CSV file **grades.csv**, containing a list of all courses and grades.
> "Feel free to use your own original grades!" 
 *-Ms. Bono circa November 2026*
> "0,0,0,0,0" 
 *-Abby Kesmodel's original history grades*
- A **Dictionary** method, to read this information into the gradebook file.
- **Updates to the main**, including case sensitivity and display of all subjects. After runs, the main also updates the csv file.
- A new class to remove grades.
- A new class to visually display data on grades. 

# Files:
- **grades.csv**, a file containing all data on grades.
- **gradebook.py**, a file for users to visualize and change their grades. These changes are implemented in grades.csv.
